# User Story Template

**As a** [role/user],
**I want to** [action/feature],
**So that** [value/benefit].

---
### Example User Stories for Full Stack Capstone Project

1. **New**: As a user, I want to register for an account so that I can personalize my experience.
2. **Backlog**: As a user, I want to log in so that I can access my account.
3. **New**: As a user, I want to view a list of all gifts so that I can browse available items.
4. **Backlog**: As a user, I want to view the details of a specific gift so that I can read its description and price.
5. **New**: As a user, I want to search for gifts by category so that I can easily find what I'm looking for.
6. **Icebox**: As a user, I want to add items to a shopping cart so that I can purchase them later.
7. **Icebox**: As a user, I want to leave a review for a gift so that I can share my experience.
8. **Technical Debt**: As a developer, I need to refactor the database connection logic so that it uses connection pooling.
